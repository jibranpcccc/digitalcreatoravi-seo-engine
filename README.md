## 🛠️ Local Development & Build

```bash
# Clone the monorepo
git clone https://github.com/jibranpcccc/digitalcreatoravi-seo-engine.git
cd digitalcreatoravi-seo-engine

# Build any individual edge site (e.g. Site 10: RAGInspect)
cd sites/site-10
npm install
npm run build
```
