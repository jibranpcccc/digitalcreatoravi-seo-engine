## 🚀 Key Technical Specifications

1. **Local-First & Client-Side Execution**: Calculators, regex parsing, and financial math execute entirely in the user's browser runtime. Zero external API lag and total user privacy.
2. **Sub-100ms Edge Delivery**: Pre-rendered as static HTML via Astro 5 and globally distributed across Cloudflare Pages, Vercel, Netlify, and GitHub Pages CDNs.
3. **Structured Semantic Data**: Every page is pre-configured with valid Schema.org JSON-LD (`SoftwareApplication`, `TechArticle`, `Dataset`, and `FAQPage`).
4. **Machine-Readable LLM Context**: Includes standardized `llms.txt` and `robots.txt` specifications to provide AI search engines (Perplexity, ChatGPT Search, Claude, Google AI Overviews) with authoritative citations.

## 🛠️ Local Development & Build

```bash
# Clone the monorepo
git clone https://github.com/jibranpcccc/digitalcreatoravi-seo-engine.git
cd digitalcreatoravi-seo-engine

# Build any individual edge site (e.g. Site 10: RAGInspect)
cd sites/site-10
npm install
npm run build
```
